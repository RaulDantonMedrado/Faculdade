Sobre o projeto

Este projeto tem como objetivo apresentar os conceitos básicos do GitHub e ensinar pessoas iniciantes a utilizar a plataforma para criar repositórios, organizar arquivos, registrar alterações e desenvolver trabalhos colaborativos.

A cartilha foi produzida com apoio da Inteligência Artificial, pesquisas na documentação oficial do GitHub e testes práticos realizados pelos integrantes do grupo.

Público-alvo

Pessoas que estão começando a aprender sobre GitHub e desejam conhecer suas principais ferramentas utilizando apenas o navegador.

Objetivos de aprendizagem
Compreender a diferença entre Git e GitHub.
Aprender a criar e organizar repositórios.
Conhecer arquivos README e Markdown.
Entender commits e histórico de alterações.
Aprender a trabalhar com colaboradores.
Conhecer branches, pull requests e merge.
Colaboração

O repositório foi criado para permitir a participação dos integrantes do grupo e o acompanhamento da professora.
