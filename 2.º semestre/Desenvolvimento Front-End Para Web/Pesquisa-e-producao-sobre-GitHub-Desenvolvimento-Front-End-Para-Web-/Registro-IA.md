**1. Ferramenta utilizada**\
Ferramenta: ChatGPT – Inteligência Artificial da OpenAI.

Finalidade: Apoiar a pesquisa sobre GitHub, esclarecer conceitos, organizar as informações da cartilha e revisar a clareza das explicações.

**2. Primeiro prompt utilizado**\
"Somos iniciantes e vamos produzir uma cartilha sobre GitHub pelo navegador. Explique o que são Git, GitHub, repositório, README, Markdown, 
commit, histórico de alterações, branch, pull request e merge. Diferencie Git de GitHub e apresente exemplos simples para estudantes iniciantes."

Finalidade do prompt: Obter explicações iniciais dos principais conceitos necessários para produzir a cartilha.

**3. Segundo prompt utilizado**\
"Explique como criar um repositório no GitHub, adicionar arquivos pelo navegador, registrar commits, convidar colaboradores e realizar uma alteração 
utilizando branch, pull request e merge. Organize as instruções em etapas numeradas e indique os cuidados necessários ao compartilhar arquivos."

Finalidade do prompt: Organizar o passo a passo das atividades práticas.

**4. Resposta da IA conferida**\
Uma das explicações utilizadas foi a diferença entre Git e GitHub.

A IA explicou que o Git é um sistema de controle de versão que registra as alterações realizadas nos arquivos, enquanto o GitHub é uma plataforma 
online que hospeda repositórios e facilita a colaboração entre pessoas.

**5. Como fizemos a verificação?**\
Para conferir essa informação, consultamos a documentação oficial do GitHub, principalmente as páginas sobre repositórios, introdução ao GitHub e commits.

Também relacionamos os conceitos com as práticas realizadas no navegador.

Durante os testes, verificamos que:
\
O repositório permite armazenar arquivos e consultar seu histórico.\
Os commits registram alterações e identificam seus autores.\
As branches permitem separar alterações da versão principal.\
Os pull requests permitem revisar alterações propostas.\
O merge incorpora as alterações à branch de destino.

**6. Ajustes realizados no conteúdo**\
As respostas da IA foram organizadas e adaptadas para uma linguagem mais simples, adequada ao público iniciante.

Também acrescentamos exemplos práticos e orientações sobre segurança, como não compartilhar senhas, tokens ou códigos de autenticação.

As instruções que dependem da interface do GitHub deverão ser conferidas durante a execução das atividades.

**7. Limitações da Inteligência Artificial**\
A IA pode apresentar informações incompletas ou instruções que não correspondem exatamente à interface atual da plataforma.

Por isso, o grupo não utilizou as respostas sem conferência.

A documentação oficial e os testes práticos foram utilizados para validar as informações.

A Inteligência Artificial contribuiu para facilitar a pesquisa, organizar os conceitos e melhorar a escrita da cartilha.
